🖥️ ReBoot-win: Лаборатория восстановления Windows
ReBoot-win — IT-проект, посвящённый экспериментам над Windows, изучению работы операционной системы и созданию собственного программного обеспечения.

Здесь находится исходный код и установочные файлы нашей флагманской утилиты — ReBoot-App.

🧪 Эксперименты: мы не просто ломаем Windows — мы изучаем, почему она работает именно так.

🛠 ReBoot-App (v1.2 Cyber Edition)
Флагманская утилита проекта — полный контроль над Windows в одном приложении.

Возможности:

✅ Дашборд с live-мониторингом CPU, RAM и диска

✅ Гипер-оптимизация системы одним кликом

✅ Деструктор UWP-приложений (Cortana, Xbox, Bing)

✅ Очистка временных файлов и кэша

✅ Проверка безопасности (Defender, Firewall, UAC)

✅ Генератор обоев — 12 палитр, 8 узоров

✅ Деинсталлятор программ

✅ Интеграция с Winget

✅ 18 вкладок функционала, 8 неоновых тем

✅ Живой фон рабочего стола с анимациями

Доступны две версии:

📦 Установочная версия (рекомендуется)

💾 Portable-версия (запуск с флешки, идеально для среды восстановления)

Скачать можно на официальном сайте ReBoot-win.
