# ReBoot-win: Лаборатория восстановления Windows 🖥️

**ReBoot-win** — это IT-проект, посвящённый экспериментам над Windows, изучению работы операционной системы и созданию собственного программного обеспечения.

Здесь находится исходный код и установочные файлы нашей флагманской утилиты — **ReBoot-App**.

---

## 🌐 Наши ресурсы (Вся экосистема проекта)

*   📺 **YouTube-канал:** (https://www.youtube.com/@ReBoot-win) — смотри реальные тесты на прочность (Удаление System32, Windows 9999 и многое другое).
*   💻 **Официальный сайт:** https://sites.google.com/view/reboot-win/home?authuser=0 — скачай программу, почитай базу восстановления и получи ранний доступ к эксклюзивному контенту.
*   🧪 **Эксперименты:** Мы не просто ломаем Windows, мы изучаем, почему она работает именно так.

## 🛠 ReBoot-App (v1.0 BETA)

Это наша фирменная утилита, созданная для помощи в диагностике и восстановлении Windows.

**Возможности:**
✅ Автоматическое обнаружение системы
✅ Инструменты восстановления Windows
✅ Работа с повреждёнными компонентами
✅ Упрощение сложных процедур восстановления

**Доступны две версии:**
*   Установочная версия (рекомендуется)
*   Portable версия (запуск с флешки, идеально для среды восстановления)
Установить их можно на официальном сайте ReBoot-win  --

## ⚠️ Внимание!
Это ПК-утилита для **Windows 10/11**. Не путайте с мобильными приложениями с похожими названиями.
