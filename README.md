## 🛠 ReBoot-App

### ⚡ v1.2 Cyber Edition

Наша флагманская утилита — полный контроль над Windows в одном приложении.

#### 🎯 Возможности

- ✅ Дашборд с live-мониторингом CPU, RAM и диска
- ✅ Гипер-оптимизация системы одним кликом
- ✅ Деструктор UWP-приложений (Cortana, Xbox, Bing)
- ✅ Очистка временных файлов и кэша
- ✅ Проверка безопасности (Defender, Firewall, UAC)
- ✅ Генератор обоев — 12 палитр, 8 узоров
- ✅ Деинсталлятор программ
- ✅ Интеграция с Winget
- ✅ 18 вкладок функционала, 8 неоновых тем
- ✅ Живой фон рабочего стола с анимациями

#### 📦 Доступные версии

| Версия | Описание |
|---|---|
| 📦 **Установочная** | Классическая установка в систему (рекомендуется) |
| 💾 **Portable** | Запуск с флешки, идеально для среды восстановления |

Скачать можно на **[официальном сайте ReBoot-win](https://sites.google.com/view/reboot-win/home?authuser=0)**.
